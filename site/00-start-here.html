What you'll build here

The scripts/ folder in this repo contains tested, ready-to-schedule jobs:

ScriptWhat it does
scripts/ai_job.pyThe general-purpose job runner: takes a prompt (plus an optional input file), runs it with logging, locking, retries, and size caps
scripts/morning_digest.pyThe morning digest pattern from Chapter 5, ready to run
scripts/watchdog.pyThe Chapter 9 watchdog: catches runaway logs, stale locks, and nightly failures
scripts/mock_ai_server.pyA pretend model endpoint, so you can test everything before trusting it

Test them any time, no model required:

python3 tests/run_tests.py

Every job script works the same way at one level: prompt in, file out, log written, lock held while running. Once that pattern clicks, you can schedule anything.

The one rule worth tattooing somewhere

A scheduled job must be safe when two of it run at once, and safe when it runs during your vacation. Everything in this book — locks, logs, retries, caps, watchdogs — flows from that. A job that's only safe when you're watching isn't scheduled; it's checked in on. We'll make it scheduled.
