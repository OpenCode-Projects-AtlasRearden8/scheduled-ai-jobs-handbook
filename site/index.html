You already know AI can do the chore. The problem isn't the chore — it's the clicking. You type the same prompt every morning. That's a job, and jobs can run on a schedule instead of you.

This handbook shows you how to hand those chores to a scheduler — Windows Task Scheduler, cron, or GitHub Actions — and to do it with local, OpenAI-compatible endpoints (Ollama included), needing no API keys, so private data stays at home.

Pick a chapter to start with; the reading order runs from judgment (what belongs on a schedule) through recipes to guardrails (logging, retries, runaway control).
